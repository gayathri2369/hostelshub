METHOD 1: COLD BOOT EMULATOR
-----------------------------
1. Close Android emulator completely
2. Open AVD Manager in Android Studio
3. Click ... (three dots) on your virtual device
4. Select "Wipe Data"
5. Start emulator (Cold Boot)
6. Wait for it to FULLY boot (2-3 minutes)
7. Run: flutter clean
8. Run: flutter run
9. Test upload again

WAIT: Let emulator fully load before testing!

═══════════════════════════════════════════════════════════

METHOD 2: CHANGE DNS (If Method 1 Fails)
-----------------------------------------
1. Windows: Settings → Network & Internet
2. WiFi → Properties (or Ethernet → Properties)
3. Scroll to "IPv4 DNS servers" → Edit
4. Set to Manual:
   Preferred DNS: 8.8.8.8
   Alternate DNS: 1.1.1.1
5. Save and restart emulator
6. Run: flutter clean
7. Run: flutter run
8. Test upload

═══════════════════════════════════════════════════════════

METHOD 3: TEST INTERNET ON DEVICE
----------------------------------
1. On emulator/device, open Chrome browser
2. Go to: https://huggingface.co
3. If page loads:
   → Internet OK, just rebuild app (flutter clean)
4. If page doesn't load:
   → Internet problem, try Method 1 or 2

═══════════════════════════════════════════════════════════

METHOD 4: USE SCRIPT (Automated)
---------------------------------
1. Open terminal in project folder
2. Run: .\fix_and_test.bat
3. Wait for rebuild
4. Test upload
